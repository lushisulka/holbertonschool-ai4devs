# Codebase Overview - Travel Map Discovery App (Legacy Version)

## Age
Initial version created in 2021. Last update in 2023.

## Size
~12,000 lines of code (JavaScript, Node.js, and some frontend components).

## Dependencies
- Node.js (v18+)  
- Express.js (backend framework)  
- MongoDB (database)  
- Mongoose (ODM)  
- JWT (authentication)  

## Issues
- Limited automated testing  
- Inconsistent code style across modules  
- Tight coupling between API and database logic  
- Incomplete error handling in some endpoints  
- Lack of proper documentation for some features
