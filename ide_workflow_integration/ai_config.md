# AI Configuration

## AI Assistant Setup
- Tool: GitHub Copilot  
- IDE: Visual Studio Code  
- Copilot enabled for all supported languages  

## Extensions Used
- GitHub Copilot  
- Prettier (code formatting)  
- YAML (for API and config files)  

## Language-Specific Rules
- JavaScript:
  - Use semicolons  
  - Follow clean and readable code style  
- Python:
  - Use type hints  
  - Follow PEP8 style guidelines  
- YAML:
  - Proper indentation (2 spaces)  
  - Clear and consistent structure  

## AI Workflows

### Code Generation
- Generate API endpoints based on requirements  
- Suggest boilerplate code  

### Code Review
- Identify bugs and performance issues  
- Suggest improvements for readability  

### Documentation Generator
- Generate Markdown documentation  
- Create API specifications (OpenAPI)
